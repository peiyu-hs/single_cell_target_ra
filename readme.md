# AI-Enabled Therapeutic Target Discovery from Single-Cell Transcriptomics in Rheumatoid Arthritis

## Overview

This project applies single-cell RNA sequencing analysis and computational target prioritization to identify disease-associated cell populations, genes, and pathways in rheumatoid arthritis.

## Objectives

- Perform quality control and preprocessing of scRNA-seq data
- Identify transcriptionally distinct cell populations
- Annotate major immune and stromal cell types
- Compare disease-associated and control populations
- Identify differentially expressed genes
- Perform pathway enrichment analysis
- Prioritize potential therapeutic targets
